# Agent 音效工作流：整段优先

本文约束 CLI 之后的 Agent 制作过程，不把游戏控制、独立音效导出或资源包编辑加入 CLI。适用于多阶段、连续演出的魔法或技能；真正独立的投射物和随机命中仍按事件制作。

## 先选播放结构

先按实际画面建立一张完整时间表，包括蓄力、变化、主冲击和自然消散。不要把每个视觉阶段直接当成一个独立生成任务。

| 类型 | 优先结构 | 不应采用 |
| --- | --- | --- |
| 一次触发、固定时间线的完整技能 | 一份完整母带、一次播放 | 多个独立音色按阶段替换 |
| 可持续、可取消的技能 | 统一音色的起音、稳定持续层、独立收尾 | 每轮重播含攻击瞬态的短片 |
| 飞弹、随机命中、多目标 | 单独事件声，沿用同一材质与空间设计 | 为连贯而提前/推迟命中 |

阶段锚点只是母带内部的自动化或事件叠加时刻，不必对应文件边界。独立音轨之间的淡化只解决幅度交接，不保证音色、空间感或叙事连续。

## 获取源材料

1. 优先向模型提交一段能力范围内的完整动作参考，提示词描述同一个声音从出现、增强、释放到消失。不要只描述多个互不相关的声音名词。
2. `grok-keyframe` 只提交首帧，不能把它声称为看过完整动作。必须保留这一限制和 `alignment_unverified`。
3. 按配置预设的实际限制检查时长。技能超过上限时，明确选择支持更长输入的已验证接口，或在 Agent 侧用统一的持续声素材构造母带并准确叠加事件。不要悄悄变速，也不要默认把每个阶段分别付费生成。
4. 所有源材料保留原始视频、任务 ID、SHA-256 与来源收据。优先复用现有可用来源；新的付费请求需有明确用途和数量，不因试听不满意自动循环付费。

## 制作一份母带

- 先确定贯穿全程的声音主体。同一能量/材质不应在阶段边界突然换成无关音色。
- 为整体设计连续的响度与频谱自动化；只对全局做最终增益与峰值控制，避免每个阶段独立归一化。
- 重要冲击在真实事件锚点叠加，不通过裁掉前段或重播开头实现。
- 空间处理应用于完整混音或共享声场，不为每个阶段重新启动不同混响。
- 源素材的延展必须写入处理记录。只允许对适合持续的纹理延展；不能重复爆炸、发射瞬态或人声来填时长。
- 先完成并试听母带，之后再生成游戏播放资源。取消、晚加入、网络延迟属于接入层，不能倒逼正常播放逐阶段换音。

## 接入与导入门禁

固定时间线正常播放优先只调用一次。没有经核实的 seek 能力时，可从同一母带预先导出少量晚加入后缀，选择一个合适入口，而不是把所有后缀都播放。

导入阶段验证后缀与母带对应样本相同，仅允许有记录的短进入淡化和量化误差。核对母带、处理方案、原始模型视频的哈希；任一改变都重新验收。不要仅因文件有声、边缘安静、解码成功就认定听感合格。

## 三层验收

| 层级 | 必查项目 | 能证明什么 |
| --- | --- | --- |
| 文件技术 | 解码、采样数、峰值、DC、首尾、来源、后缀一致性 | 文件合法、制作可追溯 |
| 连续性与调度 | 普通阶段的响度变化、频带分布变化、一次播放、取消、并发、晚加入 | 没有已知的技术性拼接/调度问题 |
| 试听与实机 | 原画面 A/B、音色统一、冲击同步、音乐/人声排除、距离与重复施放 | 最终体验；前两层不能代替 |

对普通过渡设置响度与频谱突变检查；主爆发需显式标为有意冲击，不能强行压平。阈值是报警线，不是“审美通过”的证明。最终报告分别列出技术结果、实机状态与用户试听状态；保留前后对照和可恢复备份。

## 本地实例

`D:/Documents/mc模组/特效测试` 的 `tools/mcsfx_celestial.py` 与 `tools/celestial_soundtrack_plan.json` 是一次具体实现：把天体审判的五段独立音色改为一份 16 秒母带，一条持续纹理配一个 8.4 秒冲击，并从母带导出晚加入入口。没有新模型调用。此实现并不宣称 Grok 单次生成了 16 秒，也不代表所有技能都应使用相同纹理、时长或阈值。
